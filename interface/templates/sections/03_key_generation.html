Step 2 — Key Generation (CKKS + RSA)

Two independent key pairs are generated:

  • CKKS context (secret + public): the secret key can decrypt CKKS ciphertexts and is kept only by the client. The public key allows anyone to encrypt data or perform homomorphic operations, but cannot decrypt.
  • RSA key pair: used only for the transport layer — safely moving the (large) CKKS ciphertext between client and server without needing a pre-shared secret.
